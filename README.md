# P.R.O.M.P.T. 저작권 수업 설계서

> 프롬프트보다 먼저, 저작권 — 초등 5~6학년 교과 통합형 10차시 저작권 교육

한국저작권위원회 「초등학생을 위한 알기 쉬운 저작권」 교재·교보재를 바탕으로 설계한 10차시 수업 설계서입니다.
P(Person) · R(Recognize) · O(Order of law) · M(Manner of use) · P(Play) · T(Think with AI) 6단계로 구성되어 있습니다.

## 배포 방법

1. 이 폴더의 파일을 GitHub 저장소 루트에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택합니다.
3. 1~2분 뒤 위 주소에서 확인합니다.
